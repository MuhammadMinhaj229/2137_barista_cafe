## 2024-05-18 - Tabnabbing and Placeholder-only Forms Accessibility
**Learning:** Using `target="_blank"` or `target="_new"` without `rel="noopener noreferrer"` (or at least `rel="noopener"`) can expose users to reverse tabnabbing vulnerabilities where the newly opened page can manipulate the original page. Also, placeholder text in forms is not reliably read by all screen readers and shouldn't replace standard `<label>` tags. If a design strictly requires placeholder-only forms without visible labels, they must have `aria-label` or `aria-labelledby` attributes to remain accessible. Combining existing `rel` attributes like `nofollow` or `sponsored` with `noopener` (e.g., `rel="nofollow noopener"`) is essential to preserve their original SEO functions while adding security.
**Action:** When auditing external links, always check for `target="_blank"` and append `noopener` to existing `rel` values or add it if missing. For forms missing `<label>` tags, ensure `aria-label` is applied to every `<input>` and `<textarea>`.
