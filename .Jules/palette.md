## 2026-06-20 - [Required Form Field Consistency]
**Learning:** In templates using Bootstrap, visual required indicators on forms are sometimes applied inconsistently between input types, with basic inputs like 'Name' receiving them but textareas or specific input types like 'Email' lacking them, despite all having HTML5 `required` attributes.
**Action:** When auditing forms, verify that the visual styling matches the HTML validation attributes across all fields.
